# Neural Voices Speech Dispatcher

Разработано Smit TV

## Сборка и установка

* Для сборки и установки проекта используйте скрипт `setup.sh`
* Чтобы добавить голос, создайте директорию `/usr/local/neuralvoices`
* Внутри неё разместите каталоги с голосами и файл `model.key` для каждого голоса
* Не забудьте добавить библиотеки из `libs/runtimes/linux-x64/native/lib*.so` в путь поиска динамических библиотек
* Например, можно скопировать их в `/usr/lib` или добавить директорию в `LD_LIBRARY_PATH`
